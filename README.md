# Week 7 Assignment: My Notes & The Report Builder

## Project Files
- `my_notes.py`: Python script that creates, appends to, reads, and counts lines in a text file.
- `my_notes.txt`: Text file generated by `my_notes.py` containing four lines of notes.
- `hubs.csv`: Input CSV dataset containing learner names, hubs, and test scores.
- `report_builder.py`: Python script that reads `hubs.csv`, calculates pass/fail counts and average score, and handles missing files gracefully.
- `report.txt`: Output summary report generated by `report_builder.py`.

## Question 1 Reflection
If `"a"` (append mode) were changed to `"w"` (write mode) in Question 1, opening `my_notes.txt` the second time would erase all three previously written notes. The file would be overwritten and end up containing only `"I added this later"`, reducing the final line count to 1.
